# VoiceType

Нажал горячую клавишу — сказал — текст появился там, где стоит курсор. Работает в любом приложении на Windows.

![VoiceType](docs/app.png)

Распознавание — облачные модели (OpenAI, OpenRouter, Groq) или локально, без сети и ключа. Записи сохраняются — можно переслушать, скопировать, вставить повторно.

## Установка

Скачать [VoiceType-Setup.exe](https://github.com/kirill-kopylov/voice-type/releases/latest) и запустить. При первом запуске указать API-ключ в настройках.

## Как пользоваться

1. Открой любое приложение и поставь курсор в текстовое поле
2. Нажми **Ctrl+Shift+H** — услышишь звуковой сигнал, в углу экрана появится индикатор с визуализацией голоса
3. Говори
4. Нажми **Ctrl+Shift+H** ещё раз — второй сигнал, индикатор переключится на анимацию обработки
5. Через пару секунд распознанный текст вставится в поле автоматически

Приложение работает в фоне из системного трея. Окно можно закрыть — запись по горячей клавише продолжит работать.

## Возможности

- **Запись из любого приложения** — глобальная горячая клавиша работает поверх всего
- **Автовставка** — текст сразу появляется там, где курсор. Работает в браузерах, мессенджерах, IDE, терминалах
- **История** — все транскрипции сохраняются. Можно искать по тексту, переслушивать аудио, копировать или вставлять повторно
- **Провайдеры** — OpenAI, OpenRouter, Groq или «Локально», переключается в настройках
- **Локально** — GigaAM v3 (только русский, с пунктуацией) через пакет `local-stt` (`c:\dev\local-stt`)
  в отдельном процессе: минута речи — 1,5–2 с на CPU. Модели (~230 МБ) общие с «Железным другом»,
  в `%LOCALAPPDATA%\local-stt\models`, качаются при первой диктовке или кнопкой «Проверить». Процесс
  гасится после 15 минут без диктовок

## Файлы с телефона

На телефоне с VoiceType: «Поделиться» → «На компьютер» (любые файлы, несколько сразу, текст, ссылки) или
«На компьютер» в меню выделенного текста. Всё попадает в папку **«С телефона»** на рабочем столе:
файлы — как есть (одинаковые имена получают «(2)»), ссылка — ярлыком `.url`, текст — заметкой `.txt`;
текст и ссылка ещё и копируются в буфер обмена. Папка открывается и из меню в трее.

Ход приёма — панель в правом нижнем углу: какой файл по счёту («2 из 5»), общий прогресс, скорость и сколько
ещё ждать, список файлов (клик — открыть, значок папки — показать в папке). После удачного приёма панель
гаснет сама, а если файл оборвался или телефон не дослал пачку — висит, пока её не закроют.

Работает по домашней сети, пока VoiceType запущен и задан ключ пульта (`remoteControlKey`): приём идёт на
том же порту 47821, что и прямая связь пульта (`phone-lan.ts`). Код — в `services/phone-drop/`: приём
`receiver.ts` (там же протокол), ход приёма `transfers.ts`, панель `panel.ts`. Телефон подписывает каждый
файл одноразовым HMAC ключа пары; свой адрес компьютер сообщает телефону через ретранслятор.

## MCP-сервер для нейроагентов

Настройки → «MCP-сервер для нейроагентов» → включить. Приложение поднимает локальный сервер
`http://127.0.0.1:47321/mcp` (только этот компьютер, токен в `Authorization: Bearer`). В настройках
есть готовая команда для Claude Code и JSON-конфиг для остальных клиентов.

| Инструмент | Что делает |
|---|---|
| `digest` | что было по дням: встречи с саммари и решениями, счётчики диктовок (по умолчанию 7 дней) |
| `list_meetings` | встречи без стенограмм: период, участник, слова, есть ли заметки/саммари, сортировка, страницы |
| `get_meeting` | саммари + заметки; полная стенограмма по запросу (по умолчанию режется на 20 000 символов с подсказкой, откуда продолжить; `max_chars=2000000` — всё сразу; можно диапазон секунд и спикера) |
| `search` | нечёткий или точный поиск по диктовкам, саммари, репликам и заметкам с фильтрами по дате, типу, спикеру |
| `list_dictations` / `get_dictation` | диктовки с превью и полный текст |
| `add_meeting_note` / `update_meeting_note` / `delete_meeting_note` | заметки агента к встрече (что сделано, ссылки на задачи); заметки пользователя агент менять не может |

Даты везде: `2026-10-05`, `2026-10` (месяц), `today`, `yesterday`, `7d`, `2w`. Свои заметки к встрече
пользователь добавляет в карточке встречи; агентские помечены значком робота.
